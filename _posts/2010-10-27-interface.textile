h2. Input format (PIN)

Percolator accepts a tab-delimited input file (PIN format) where each row
describes one peptide-spectrum match (PSM):

<pre><code>id \t label \t scannr \t feature1 \t ... \t featureN \t peptide \t proteinId1 \t ... \t proteinIdM
</code></pre>

* @label@ is @1@ for target PSMs and @-1@ for decoys.
* Features are numerical values used by the SVM.
* The @peptide@ column uses the format @X.PEPTIDE.X@ where X is the flanking amino acid.

PIN files are typically generated by converters such as
"crux":https://crux.ms, "ms2rescore":https://ms2rescore.readthedocs.io, or
"oktoberfest":https://oktoberfest.readthedocs.io.

h2. qvality

Qvality estimates posterior error probabilities (PEP) and q-values from a
set of target and decoy scores.

<pre><code>qvality [options] target_scores.txt decoy_scores.txt
</code></pre>

Alternatively, accurate p-values can be provided in a single file.

<table>
  <thead>
    <tr><th>Option</th><th>Description</th></tr>
  </thead>
  <tbody>
    <tr><td><code>-v &lt;level&gt;</code>, <code>--verbose &lt;level&gt;</code></td><td>Set verbosity of output: 0=no processing info, 5=all. Default = 2.</td></tr>
    <tr><td><code>-s &lt;value&gt;</code>, <code>--epsilon-step &lt;value&gt;</code></td><td>Relative step size threshold before cross-validation error is calculated.</td></tr>
    <tr><td><code>-n &lt;bins&gt;</code>, <code>--number-of-bins &lt;bins&gt;</code></td><td>The number of spline knots used when interpolating spline function. Default is 500.</td></tr>
    <tr><td><code>-c &lt;value&gt;</code>, <code>--epsilon-cross-validation &lt;value&gt;</code></td><td>Relative cross-validation step size threshold for ending iterations.</td></tr>
    <tr><td><code>-r</code>, <code>--reverse</code></td><td>Indicate that lower scores are better (reversed scoring).</td></tr>
    <tr><td><code>-o &lt;file&gt;</code>, <code>--output-file &lt;file&gt;</code></td><td>Output results to file instead of stdout</td></tr>
    <tr><td><code>-Y</code>, <code>--tdc-input</code></td><td>Turn off the pi0 correction for results from a concatenated target-decoy database.</td></tr>
    <tr><td><code>-d</code>, <code>--include-negative</code></td><td>Include decoy probabilities in the output.</td></tr>
  </tbody>
</table>

h2. picked-protein

Picked-protein infers protein-level FDR from Percolator peptide output.

<pre><code>picked-protein -i percolator_peptides.tsv -d database.fasta -o proteins.tsv
</code></pre>

<table>
  <thead>
    <tr><th>Option</th><th>Description</th></tr>
  </thead>
  <tbody>
    <tr><td><code>-v &lt;level&gt;</code>, <code>--verbose &lt;level&gt;</code></td><td>Set verbosity of output: 0=no processing info, 5=all. Default = 2.</td></tr>
    <tr><td><code>-i &lt;filename&gt;</code>, <code>--peptide-in &lt;filename&gt;</code></td><td>Tab-delimited peptide results file from Percolator.</td></tr>
    <tr><td><code>-d &lt;filename&gt;</code>, <code>--database &lt;filename&gt;</code></td><td>Protein sequence database in FASTA format.</td></tr>
    <tr><td><code>-o &lt;filename&gt;</code>, <code>--protein-out &lt;filename&gt;</code></td><td>Output file for inferred protein results.</td></tr>
  </tbody>
</table>
